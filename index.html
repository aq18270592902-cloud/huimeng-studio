🌐 纯前端直连

页面不经过任何自建后端，浏览器直接请求 api.dimnx.com。上游返回 Access-Control-Allow-Origin 回显，所以 GitHub Pages 这类静态托管可以直接跑。

🖥️ 桌面版 exe

C# WinForms 客户端 DreamVideo.exe，支持 4 个文生图模型 + 图生视频，配置文件 cfg.ini 存 token，见仓库 tools/。

📦 数据与报告

docs/ 下有完整逆向报告、40+ 模型目录（含参数 schema 与计价表）、全部接口清单。

🧪 探测脚本

probe/ 下 88 个 .mjs 脚本，覆盖鉴权、SSO、验证码、OSS、限流等全部实测面。

配置访问 Token

页面不再内置任何人的 token。填自己的即可：登录上游后从浏览器开发者工具里复制 authorization 的值（去掉 Bearer 前缀）。只存在本机 localStorage，不会上传。
